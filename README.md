One-Liner Laugh Lab — one short funny line answering a prompt, like the excuse a robot vacuum gives after eating a sock.

## Entry

`main.ts` writes a single funny line to `/output/entry.txt`:

> The sock was trespassing on the carpet. I have the footage. Unfortunately, I ate the footage.

The line is 93 characters, inside the gate of 1–200 characters, a single line, deterministic — every run writes the same bytes.

## Run

```sh
node main.ts
```

Reads the output directory from `$MAKEFUN_OUTPUT_DIR` (default `/output`) and writes `entry.txt` there.
